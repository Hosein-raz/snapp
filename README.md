## 📖 About The Project

This repository contains a comprehensive, multi-page frontend UI clone of the **Snapp Super Application** (Iran's leading ride-hailing and everyday services platform). Built entirely from scratch using pure HTML and CSS, this project demonstrates the ability to architect, style, and maintain a large-scale web application with multiple distinct routing pages and complex responsive layouts.

## ✨ Key Technical Features

This project was developed with a strong focus on clean code architecture, modularity, and modern CSS practices:

* **Multi-Page Architecture:** The application is split into four fully functional, interconnected static pages:
  * `index.html`: The main Super App landing page featuring a comprehensive service grid.
  * `driver-register.html`: A detailed driver registration portal including an interactive income calculator.
  * `drivers-club.html`: The Drivers Club page featuring promotional sliders and news grids.
  * `snapp-pay.html`: The Snapp Pay (Credit Service) landing page with custom blue branding and purchasing step UI.
* **Modular CSS Structure:** Instead of a single monolithic stylesheet, the project utilizes dedicated style and responsive CSS files for each individual page (e.g., `dr-style.css`, `snapp-pay-responsive.css`) to ensure high maintainability.
* **CSS Variables (Custom Properties):** Extensive use of `:root` variables for strict theme and color management across different brand identities (e.g., Green for the main app, Blue for Snapp Pay).
* **Semantic HTML5:** Utilizing modern tags such as `<details>` and `<summary>` for native, JavaScript-free FAQ accordions.
* **Fully Responsive:** Pixel-perfect adaptations across Mobile, Tablet, and Desktop resolutions using strategic `@media` queries.

## 🚀 How to Explore

1. Clone the repository to your local machine:
```
git clone https://github.com/Hosein-raz/snapp.git
```
2. Open the project directory.
3. Launch index.html in your web browser to start exploring the Super App clone. Use the navigation bar to switch between the different services and pages.
